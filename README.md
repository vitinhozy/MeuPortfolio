# 🚀 Portfólio Profissional — Victor Castro

Bem-vindo ao meu portfólio!  
Este projeto foi desenvolvido para apresentar minhas habilidades, projetos, experiências profissionais e trajetória na área de tecnologia e dados.

🔗 **Acesse o site:**  
➡️ https://portfoliovictor3.netlify.app/

---

## 📄 Sobre o Projeto

Este portfólio é um site moderno, responsivo e otimizado, criado para demonstrar meus conhecimentos em desenvolvimento web e destacar minhas competências em **Python, SQL, Power BI, ETL, automações e análise de dados**.  

O objetivo é proporcionar uma navegação clara e objetiva, apresentando minhas conquistas, projetos e contato de forma profissional.

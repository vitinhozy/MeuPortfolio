O QUE NÃO FOI CLONADO / LIMITAÇÕES
================================================================================

⚠️ Imagens: O site original contém imagens que não foram incluídas por razões
   de direitos autorais. Você deve adicionar suas próprias imagens na pasta
   assets/images/

⚠️ Fontes Customizadas: Se o site original usava fontes especiais, elas foram
   substituídas por fontes do sistema (stack seguro). Você pode adicionar suas
   próprias fontes em assets/fonts/

⚠️ Conteúdo Dinâmico: O site original pode ter conteúdo carregado via JavaScript
   ou APIs. Este template é estático - você deve editar manualmente o HTML para
   adicionar seus dados.

⚠️ Analytics e Rastreadores: Google Analytics, Facebook Pixel e outros
   rastreadores foram removidos por privacidade. Você pode adicioná-los
   manualmente se desejar.

⚠️ Formulários Backend: O formulário de contato usa mailto: por padrão.
   Para funcionalidade real, integre um serviço como Formspree, EmailJS ou
   configure um backend próprio.

⚠️ Integração com APIs: Qualquer integração com APIs externas foi removida.
   Você pode adicionar novamente conforme necessário.

================================================================================
COMO USAR ESTE TEMPLATE
================================================================================

1. EDITAR INFORMAÇÕES PESSOAIS:
   - Abra index.html com um editor de texto
   - Procure por "Seu Nome", "seu.email@exemplo.com", etc.
   - Substitua com suas informações reais

2. ADICIONAR IMAGENS:
   - Coloque suas imagens em assets/images/
   - Referencie no HTML: <img src="assets/images/sua-imagem.jpg">

3. PERSONALIZAR ESTILOS:
   - Edite assets/css/styles.css
   - Altere cores, fontes, tamanhos conforme desejado

4. ADICIONAR FUNCIONALIDADES:
   - Modifique assets/js/main.js para adicionar scripts
   - Adicione novas seções no HTML conforme necessário

5. TESTAR LOCALMENTE:
   - Use um servidor local (Python, Node.js, PHP)
   - Não abra diretamente via file:// para evitar problemas CORS
